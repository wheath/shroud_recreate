# Reference image — public domain

This directory holds the **default reference image** shown in the app for visual
comparison against the projected render. It is loaded automatically on page init;
users may also load their own reference image (which stays in the browser).

## File

- `shroud_of_turin_pos_neg_face.jpg` — a face view of the Shroud of Turin showing
  the positive and the photographic negative (in which the image reads as a
  coherent face).

## Provenance / licence

The Shroud was first photographed by **Secondo Pia in 1898**; the striking
negative image dates from that work. Photographs of this age are in the **public
domain**, and Wikimedia hosts the source under **PD-Art / PD-old**
(a faithful photographic reproduction of a public-domain work carries no new
copyright).

- Status: **Public domain** (PD-Art / PD-old-100)
- Origin: Secondo Pia, 1898 (and subsequent public-domain reproductions)
- Source: Wikimedia Commons — https://commons.wikimedia.org/wiki/Category:Secondo_Pia

Because it is public domain, no attribution is legally required; this note is
kept for transparency about where the image comes from and why it is safe to
include. See also the repository's imagery policy in `.gitignore` and `README.md`.
