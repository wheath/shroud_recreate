# Shroud-ify

Turn any photo of a face into a Shroud-of-Turin-like image, using a single,
physically-grounded procedural image-formation engine that runs identically in
the browser (Pyodide/WASM) and on the desktop (native Python).

The engine models the Shroud image the way the relic appears to encode it: as a
function of the **distance** between a draped cloth and a face, sampled through a
hand-loomed weave, with no hard edges or lighting cues — a soft, fibre-scale,
half-tone image. See [`docs/BACKLOG.md`](docs/BACKLOG.md) for the roadmap.

## Repository layout

```
shroud_core/     the shared cv2-free NumPy/SciPy engine  (the source of truth)
web/             web app  — Pyodide + MediaPipe (browser, 100% client-side)
desktop/         desktop app — Python GUI reusing shroud_core
tests/           engine tests (smoke, determinism, validation)
docs/            backlog, architecture notes
```

## Quick start (engine)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pytest -q
```

Minimal use:

```python
import numpy as np
from shroud_core import shroudify

# Z_skin: face depth toward the cloth (larger = nearer); valid: where the face is.
img = shroudify(Z_skin, valid, ppcm=10.0, contrast=0.30, max_opacity=0.72, sepia=True)
# img is an (H, W, 3) uint8 RGB array
```

To go from a **photo** to `Z_skin` you supply face-mesh landmarks (e.g. MediaPipe
FaceMesh) to `landmarks_to_depth(pts, H, W)` — see the `epic:geometry` issues.

## Validation criteria

An output is considered faithful when it passes two non-pixel-wise tests:

1. **2D FFT** → a smooth, isotropic diamond with no needle-spikes
   (high-frequency tail ≈ 0.007 vs. the real relic ≈ 0.004).
2. **VP-8 self-consistency** → a naive intensity-to-height plot reconstructs a
   coherent, proportioned face (no crater eyes, knife-edge nose, or hairline wall).

## A note on imagery

This repository intentionally contains **no photographs of the Shroud of Turin**.
Such photographs are third-party, rights-controlled works. All images the project
produces are procedural renders generated by this code; they are treated as
build outputs and are git-ignored rather than committed. Do not add Shroud
photographs to the repository.
