# Web app (Pyodide / WASM)

Browser front-end that runs the exact `shroud_core` engine client-side via
Pyodide, with MediaPipe FaceMesh (JS) for photo → geometry. 100% local — no
image ever leaves the browser.

To be built under the `epic:web` issues. See [`../docs/BACKLOG.md`](../docs/BACKLOG.md).
